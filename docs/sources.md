# 根拠にした資料

このアプリの目標症例数と、受験要件のチェックリストは、次の資料に基づいています。**学会の基準は改訂されることがあります。申請の前に、最新の資料で必ず確認してください。** 非公式のツールで、学会とは関係ありません。

画面（進捗タブ・設定タブ）の各専門医のカードにも、同じ内容の根拠が書いてあります。

## 症例数の目標

### 放射線科専門医（基本領域）

| 項目 | 目標 | 根拠 |
|---|---|---|
| X線単純撮影 | 400 | 研修手帳の様式（経験症例記録）の各シートの題 |
| 消化管X線 | 60 | 同上 |
| 超音波 | 120 | 同上 |
| CT | 600 | 同上 |
| MRI | 300 | 同上 |
| 核医学 | 50 | 同上 |
| IVR | 30（血管系10以上、非血管系5以上） | 同上 ＋ 学会の専門研修プログラム |
| 放射線治療 | 30（4部位それぞれ4以上） | 同上 ＋ 学会の専門研修プログラム |
| 疾患・病態 | 100枠のうち90以上 | 様式「A.疾患」の題（目標90疾患以上） |

学会の専門研修プログラムは、日本医学放射線学会が作成したもの（2015年12月承認、2023年5月修正版）です。

### 診断専門医

日本専門医機構「専攻医研修手帳（放射線診断領域）」の「経験症例記録」（2023年12月付のファイル）にある、専門研修が満了するまでの目標です。

| 項目 | 目標 |
|---|---|
| X線単純撮影 | 400 |
| 消化管X線検査 | 40 |
| 超音波検査 | 50 |
| CT | 1500 |
| MRI | 1000 |
| 核医学検査 | 60 |
| IVR | 40 |

- IVRの血管系・非血管系の内訳は、研修手帳に数字がなかったため、未設定にしてあります（研修手帳には「手技・治療内容によりそれぞれ目標の症例数が設定されている」とだけあります）。血管系・非血管系を合わせて10例までは、画像診断のみの検査を含めてよい、とされています
- 実地診療で目標に届かないときは、講習会などで補う（ただしCT・MRI・核医学検査は、講習会等による補完は認められない）と書かれています
- 基本領域で経験した症例を数える「連動研修」や「ポイント制」があります。詳しくは、機構の整備基準（放射線診断領域、第2版）を見てください。このアプリでは自動計算しません

### 治療専門医

日本専門医機構「専攻医研修手帳（放射線治療領域）」の「経験症例記録」（2023年12月付のファイル）にある、専門研修が満了するまでの目標です。

| 項目 | 目標 |
|---|---|
| 部位別の経験症例（合計） | 200例以上 |
| 脳・頭頸部 | 30例以上 |
| 胸部（肺・食道・乳腺・胸部転移巣） | 30例以上 |
| 腹部・骨盤部 | 30例以上 |
| 四肢・皮膚・その他 | 設定なし |
| 治療技術（合計） | 30件以上 |
| 密封小線源治療 | 5件以上 |
| 高精度放射線治療（強度変調＋定位の合計） | 10件以上 |
| 　強度変調放射線治療 | 5件以上 |
| 　定位放射線照射 | 5件以上 |
| 特殊治療（粒子線、全身照射、全リンパ節照射、全脳全脊髄照射、術中照射、小児腫瘍） | 設定なし |

- 部位別の症例数と、治療技術の件数は、**重複して数えられます**（例：前立腺癌の強度変調放射線治療は、腹部・骨盤部の1例と、強度変調放射線治療の1件）
- 1連の治療（3か月以内の同一疾患）は1例です。治療目的が同じで複数の部位に照射する場合も1例です
- 基本領域の研修で必要な件数に達したあと、2年目以降に経験した症例は、「連動研修」として含めてよい。上限は、部位別が40例（1/5）、治療技術が6件です。このアプリは自動では区別しません

## 受験要件のチェックリスト

| 専門医 | 根拠 |
|---|---|
| 放射線科専門医 | 日本医学放射線学会の専門医試験案内（第6回、2026年4月7日掲載）https://www.radiology.jp/specialist/s_information/20260407_01.html |
| 診断専門医 | 診断専門医試験案内（第3回、2026年4月7日掲載）https://www.radiology.jp/specialist/s_information/20260407_02.html、および専攻医研修手帳（放射線診断領域）の「学術業績・講習会受講実績」 |
| 治療専門医 | 治療専門医試験案内（第1回、2024年4月9日掲載）https://www.radiology.jp/specialist/s_information/20240409_03.html、および専攻医研修手帳（放射線治療領域）の「学術業績・講習会受講実績」 |

研修手帳に書かれていた、症例数以外の要件は次のとおりです。

- 診断・治療とも、専門研修の2年間のうちに、**筆頭者として学術集会で発表**し、**筆頭著者または共著者として論文を発表**する
- 講習会：医療安全・感染対策・医療倫理を、それぞれ受講する（診断は各1回以上。治療は、医療安全に放射線防護を含む）

発表や論文の「件数」は、研修手帳には書かれていません。チェックリストは、実際の要件を満たしたかの目安です。

## 確認できなかったこと

- 診断・治療の研修手帳は、公開されているページから入手先を確認できませんでした（会員向けの資料の可能性があります）。このリポジトリには含めていません。版が改訂されている可能性があります
- 日本放射線腫瘍学会の側の要件（会員年数など）は、学会のページを開けず、日本医学放射線学会の試験案内に書かれている範囲だけを載せています
- 放射線科専門医の「講習会」は、2012年の案内（https://www.radiology.jp/specialist/s_information/20120215_2.html）しか確認できておらず、現在の要件と違う可能性があります。そのため、チェックリストには「研修プログラムが定める講習会の受講記録」とだけ書いてあります
- サブスペシャルティ領域の細かい規定（日本専門医機構の整備基準）は、全文は確認していません
