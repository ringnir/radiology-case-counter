# 複数人で使う：Googleスプレッドシート＋Apps Script のセットアップ手順

科内・研修施設・同期など、**複数人の症例数をまとめて管理したい人（管理者）向け**の手順です。所要時間は、はじめてなら30〜40分ほど。プログラミングの知識は要りません（コピーして貼り付けるだけです）。メンバー側は、URLを開いて登録するだけです（Googleアカウントは不要）。

**この手順の読み方**：各手順は「やること」「確認」「うまくいかないとき」の順に書いてあります。**「確認」に書いたものが画面で見えたら、次に進んでください。** 見えないときは、その手順の「うまくいかないとき」と、最後の[困ったとき](#困ったとき)を見てください。

## 全体のしくみ

```
メンバーのブラウザ ──→ Apps Script の「ウェブアプリ」 ──→ データ用スプレッドシート
（スマホ・PC）          （管理者のGoogleアカウントで動く）     （管理者のドライブに自動で作られる）
        ↑ Googleサイトに埋め込んでも、URLを直接開いてもよい
```

- **管理者のGoogleアカウントで動きます**。メンバーはGoogleアカウント不要で、このアプリの「氏名＋パスコード」でログインします
- 症例のデータは、管理者のドライブにできるスプレッドシート1つに保存されます（サーバーを借りる必要はなく、無料のGoogleアカウントで動きます）
- 管理者は、全員の進捗を一覧で見たり、入学年度で絞り込んだり、メンバーの記録を開いて研修手帳の様式で出力したりできます。メンバー同士は、お互いの記録を見られません

## 用語

| 言葉 | 意味 |
|---|---|
| Apps Script | Googleが提供している、スプレッドシートなどを動かす小さなプログラムの置き場所。このアプリのサーバー側はここで動きます |
| プロジェクト | Apps Script の中の、ひとまとまりのプログラム（この手順では `Code.gs` と `Index.html` の2ファイル） |
| ウェブアプリ・デプロイ | プログラムを、URLで開けるWebページとして公開すること。**コードを書き換えても、デプロイし直すまでURLの中身は変わりません** |
| 実行ログ | エディタの下に出る、プログラムの実行結果のメッセージ |
| 管理者パスコード | 管理者としてログインするための合言葉（`Code.gs` に書く） |
| 招待コード | メンバーが新規登録するための合言葉（`Code.gs` に書く。メンバーにだけ教える） |
| `setup` | データ用スプレッドシートを作るための関数。最初に1回、エディタから実行する |

## 用意するもの

| 用意するもの | 内容 |
|---|---|
| Googleアカウント | 管理者用。**長く使い続けられるもの**にしてください（異動・退職でなくなるアカウントだと、データごと失われます）。大学・病院の組織アカウントは、外部への公開が禁止されていて手順5で詰まることがあります。その場合は、個人のGoogleアカウントで作るか、組織の管理者に確認してください |
| パソコン | 設定作業用。スマホだけでは難しいです |
| **管理者パスコード** | 管理者がログインするための合言葉。**8文字以上**。あらかじめ決めておく |
| **招待コード** | メンバーが新規登録するときの合言葉。**6文字以上**。あらかじめ決めておく（メンバーにだけ伝える） |
| 所属施設への確認 | 症例のデータを、院外のクラウド（Google）に置いてよいか。[安全面と制限](#患者さんの情報について)を読んで、必要なら情報セキュリティの担当に確認してください |

**2つのコードの決め方**

- 管理者パスコードと招待コードは、**別の文字列**にします。ほかのサービスのパスワードの使い回しは避けてください
- 使う文字は、**半角の英数字と `-`（ハイフン）・`_`（アンダースコア）だけ**にしてください。`'`（引用符）・`"`・`\`・空白・全角文字は、`Code.gs` に書いたときに動かなくなる原因になります
- 例：管理者パスコード `kanri-2026-xyz`、招待コード `nyugaku2026`（**この例はそのまま使わないでください**）
- 決めたら、パスワード管理ツールなど、**自分だけが見られる場所に控えて**おきます（更新のときに、もう一度書く必要があります）

## 手順0. ファイルを手元に用意する

**やること**

1. このリポジトリのトップ（[github.com/ringnir/radiology-case-counter](https://github.com/ringnir/radiology-case-counter)）で、緑の **「Code」ボタン → 「Download ZIP」** を押す
2. ダウンロードした ZIP を解凍する（ダブルクリック、または右クリック →「すべて展開」）
3. 解凍してできたフォルダの中の `apps-script` フォルダを開く

**確認**

- `apps-script` フォルダに、`Code.gs` と `Index.html` の2つのファイルがある
- この2つを、**メモ帳（Windows）やテキストエディット（Mac）などのテキストエディタ**で開ける（`Index.html` をダブルクリックするとブラウザが開きます。それは違うので、右クリック →「プログラムから開く」で、テキストエディタを選んでください。Macでテキストエディットを使うときは、「フォーマット → 標準テキストにする」にしてから開きます）

（Gitに慣れている人は、リポジトリをクローンしても同じです。）

**うまくいかないとき**

- `Code.gs` を開くアプリが分からない：拡張子が `.gs` のため、アプリが関連づけられていないだけです。「プログラムから開く」でメモ帳（テキストエディット）を選んでください
- 中身が文字化けして読めない：エディタの文字コードをUTF-8にしてください（Windowsのメモ帳なら、開くときに「エンコード：UTF-8」を選びます）

## 手順1. Apps Script のプロジェクトを作る

**やること**

1. ブラウザの右上のアイコンで、**管理者に使うGoogleアカウントでログインしている**ことを確認する（複数のアカウントでログインしているときは、いったん管理者用のアカウントに切り替えるか、**Chromeのプロフィールを分ける**と、取り違えを防げます）
2. **<https://script.google.com>** を開く
3. 左上の **「新しいプロジェクト」** を押す
4. エディタが開いたら、左上の「無題のプロジェクト」をクリックして、わかりやすい名前（例：`専門医症例カウンター`）に変えて、「名前を変更」を押す

**確認**

- 画面の左に、ファイルの一覧（**`Code.gs`** が1つ入っています）、真ん中にコードの編集欄がある
- 編集欄に `function myFunction() { }` と書いてある
- 左端の縦のメニューに「エディタ」「トリガー」「実行数」「プロジェクトの設定」などが並んでいる

**うまくいかないとき**

- 「新しいプロジェクト」が見つからない：画面の左上、または「マイプロジェクト」の一覧の上にあります。見つからなければ、<https://script.new> を開くと、新しいプロジェクトが作られます
- 「Apps Script を利用できません」と出る：組織のGoogleアカウントで、管理者が Apps Script を止めていることがあります。個人のGoogleアカウントで作ってください

## 手順2. Code.gs を貼り付けて、2つのコードを設定する

**やること**

1. 手元の `apps-script/Code.gs` を、テキストエディタで開き、**中身をすべて選択してコピー**する（Ctrl＋A → Ctrl＋C。Macは ⌘＋A → ⌘＋C）
2. Apps Script のエディタに戻り、左のファイル一覧で **`Code.gs`** をクリックする
3. 編集欄をクリックして、中身を**すべて選択して削除**（Ctrl＋A → Delete）
4. コピーした内容を**貼り付ける**（Ctrl＋V。Macは ⌘＋V）
5. 先頭近くにある、次の2行を探す（編集欄の中で Ctrl＋F を押して `ADMIN_PASSCODE` と入力すると、すぐに見つかります）

   ```js
   const ADMIN_PASSCODE = '';   // 管理者パスコード（8文字以上）
   const JOIN_CODE = '';        // 招待コード（メンバーが新規登録するときの合言葉・6文字以上）
   ```

6. 引用符 `' '` の**間に**、決めておいたコードを書く。例：

   ```js
   const ADMIN_PASSCODE = 'kanri-2026-xyz';
   const JOIN_CODE = 'nyugaku2026';
   ```

   - 引用符は消さない・全角にしない。行末の `;` も消さない
   - 書き換えるのは、この2行の**引用符の中だけ**です。`//` から後ろの説明は、そのままで構いません
7. **保存**する（Ctrl＋S。Macは ⌘＋S。または、上のフロッピーディスクのアイコン）

**確認**

- ファイルの一番上が `/**` で始まり、**専門医症例カウンター（複数人管理版） サーバー側コード** という説明が見える
- 2行に、自分で決めたコードが入っていて、引用符で囲まれている
- ファイルの一番下まで行くと、`}` で終わっている（最後まで貼り付けられている）
- 保存したあと、上のバーに「保存中…」「保存しました」のような表示が出る

**うまくいかないとき**

- 貼り付けたら、元の `function myFunction() {}` が残ってしまった：貼り付ける前の「中身をすべて選択して削除」をしていません。もう一度、すべて選択して削除してから貼り付けてください
- 管理者パスコードは8文字以上、招待コードは6文字以上です。足りないと、あとで「初期設定が終わっていません」と表示されます

> **このコードを書き込んだ `Code.gs` は、GitHubなどに載せないでください。** コードは平文で書かれます。

## 手順3. Index.html を追加して貼り付ける

**やること**

1. 左のファイル一覧の上にある **「ファイルを追加」（＋のアイコン）→ 「HTML」** を選ぶ
2. ファイル名を入力する欄が出るので、**`Index`** と入力して Enter（**`.html` は付けない**。先頭だけ大文字で、`Index` とそのとおりに）
3. 新しくできたファイルが開く。**中身には最初から数行のHTMLが入っているので、すべて選択して削除**する
4. 手元の `apps-script/Index.html` を、テキストエディタで開き、**中身をすべてコピー**して、ここに**貼り付ける**（約300KBあり、貼り付けに数秒かかります。固まったように見えても、少し待ってください）
5. 保存する（Ctrl＋S）

**確認**

- 左のファイル一覧に、**`Code.gs` と `Index.html` の2つ**が並んでいる（`Index.html.html` や `index.html` ではない）
- `Index.html` の一番下が、`</html>` で終わっている

**うまくいかないとき**

- ファイル名を間違えた：ファイル名の右の「︙」→「名前を変更」で、`Index` に直せます（拡張子は自動で付きます）
- 貼り付けに失敗して、途中で切れている：すべて削除して、もう一度コピーし直してください。コピーするときは、必ず**Ctrl＋Aで全選択してから**コピーします

## 手順4. setup を実行してデータ置き場を作る

`setup` は、データを保存するスプレッドシートを自動で作る関数です。**最初に1回だけ**実行します。

**やること**

1. エディタ上部の関数の選択欄（「デバッグ」ボタンの右。初めは `myFunction` などと出ている）を押して、**`setup`** を選ぶ
2. **「実行」** を押す
3. 初回は **「承認が必要です」** と出るので、**「権限を確認」** を押す（別のウィンドウが開きます。**ポップアップがブロックされている**と開かないので、そのときは、アドレス欄の右のポップアップのアイコンから許可してください）
4. 管理者用の**Googleアカウントを選ぶ**
5. 「**Google hasn’t verified this app**（このアプリは Google で確認されていません）」と出たら、**左下の「詳細」→「（プロジェクト名）（安全ではないページ）に移動」** を押す
   - これは、**自分で作ったスクリプトが、Googleの審査を受けていない**ために出る、通常の表示です。この手順のスクリプトは、あなた自身が作ったものなので、そのまま進んで構いません
6. 「**スプレッドシートの表示、編集、作成、削除**」の権限を求められるので、**「許可」** を押す
   - この権限は、データ用のスプレッドシートを作って読み書きするために必要です。Googleの仕組み上、「すべてのスプレッドシート」と表示されますが、このアプリのコードが読み書きするのは、`setup` が作る**データ用スプレッドシート1つだけ**です（コードは `Code.gs` で確認できます）
7. 権限を許可すると、自動でそのまま実行されます。されなかったときは、もう一度「実行」を押す

**確認**

- 画面の下に **「実行ログ」** が出て、次のように表示される（文言は、多少違うことがあります）

  ```
  実行を開始しています
  準備ができました。次はデプロイ（ウェブアプリ）に進んでください。データ保存先: https://docs.google.com/spreadsheets/d/…
  実行が完了しました
  ```

- Googleドライブ（<https://drive.google.com>）の「マイドライブ」に、**`専門医症例カウンター_データ（直接編集しないでください）`** というスプレッドシートができている。開くと、下のタブに **`members`・`docs`・`config`** の3つのシートがある（中身は、今は見出しの行だけ）

**うまくいかないとき**

| 表示 | 原因と対処 |
|---|---|
| 「先に、このファイル上部の ADMIN_PASSCODE と JOIN_CODE を書き換えてから、もう一度 setup を実行してください。」 | 手順2の設定が足りません。2つのコードを書き（管理者パスコード8文字以上、招待コード6文字以上）、**保存してから**、もう一度 `setup` を実行する。スプレッドシートは、すでに作られています（作り直されません） |
| 実行ログが出ない／「実行」を押しても何も起きない | 関数の選択欄が `setup` になっていますか。画面の下の「実行ログ」の欄が、閉じていないか確認してください |
| `ReferenceError` や `SyntaxError`（構文エラー）と赤く出る | `Code.gs` が最後まで貼り付けられていない、または、コードを書くときに引用符などを消してしまっています。手順2をやり直してください |
| 承認の画面が出ない | ポップアップがブロックされています。許可してから、もう一度「実行」 |
| 承認のあと、「このアプリはブロックされました」と出る | 組織のGoogleアカウントで、管理者が許可していないことがあります。個人のGoogleアカウントで作るか、組織の管理者に確認してください |

`setup` は、何度実行しても、すでにあるデータは消えません。

## 手順5. ウェブアプリとしてデプロイする

**やること**

1. エディタ右上の **「デプロイ」→「新しいデプロイ」** を押す
2. 「種類を選択」の横の**歯車アイコンを押して、「ウェブアプリ」** を選ぶ
3. 次のように設定する

   | 項目 | 設定 |
   |---|---|
   | 説明 | 空欄でも、`初版` などでもよい |
   | 次のユーザーとして実行 | **自分（管理者のメールアドレス）** |
   | アクセスできるユーザー | **全員** |

   - 「全員」にするのは、メンバーがGoogleにログインしなくても使えるようにするためです。アプリ自体のログイン（氏名＋パスコード）があるので、パスコードなしでは中身は見られません
   - 「Google アカウントを持つ全員」ではありません。**「全員」**を選んでください
4. **「デプロイ」** を押す（承認を求められたら、手順4と同じ流れで許可）
5. 「デプロイを更新しました」と出て、**「ウェブアプリ」のURL**（`https://script.google.com/macros/s/…/exec`）が表示される。**「コピー」を押して、メモ帳などに貼り付けて保存**しておく
6. 「完了」を押す

**確認**

- コピーしたURLが、**`https://script.google.com/macros/s/` で始まり、`/exec` で終わっている**
- あとでURLを確認したいときは、「デプロイ」→「デプロイを管理」で、もう一度見られます

**うまくいかないとき**

- 「アクセスできるユーザー」に **「全員」の選択肢がない**：組織（大学・病院）のGoogleアカウントで、管理者が外部への公開を禁止している可能性が高いです。次のどれかにしてください
  - 個人のGoogleアカウントで、手順1からやり直す（おすすめ）
  - 組織のGoogle管理者に、「Apps Script のウェブアプリを、組織外にも公開したい」と相談する
  - メンバー全員が、同じ組織のGoogleアカウントでログインできる場合に限り、「（組織名）内の全員」でも使えることがあります。ただしその場合、メンバーはGoogleにログインした状態で開く必要があります（複数のアカウントでログインしていると、開けないことがあります）
- 「デプロイをテスト」にも URL が出る：そちらは `/dev` で終わる**自分専用のテスト用URL**です。メンバーには渡さないでください。メンバーに渡すのは、必ず `/exec` のURLです

## 手順6. 動作を確認する

**必ず、実際に1回通して試してください。** ここで確認しておくと、メンバーに案内したあとのトラブルを防げます。

**やること**

1. Chromeの**シークレットウィンドウ**（Ctrl＋Shift＋N。Macは ⌘＋Shift＋N）を開き、コピーしたURLを開く（Googleにログインしていない人が開いたときと同じ状態で確認できます）
2. **ログイン画面**が出る。ログイン画面の上のタブで **「管理者」** を選び、管理者パスコードを入れてログインする → 「全員の進捗」（まだ0人）の画面になる
3. いったんログアウトし、**「新規登録」** で、テスト用の氏名・パスコード（6文字以上）・招待コードを入れて登録する
4. 症例を1件登録して、右上の表示が **「保存済み」** になることを確認する
5. もう一度ログアウトして、**「管理者」** でログイン → 一覧に、テスト用のメンバーが出ていることを確認する
6. その氏名を押して、記録が閲覧のみで開くことを確認する
7. 「メンバー管理」で、テスト用のメンバーを削除する（確認が2段階で出ます）
8. （できれば）**スマートフォン**でも、同じURLを開いて、ログインできることを確認する

**確認**

| 場面 | 見えるはずのもの |
|---|---|
| URLを開く | 「専門医症例カウンター」のログイン画面（最初は、少し読み込みに時間がかかることがあります。画面の上に、Googleのアプリであることの注意書きが出ることがありますが、正常です） |
| 管理者でログイン | 「全員の進捗」の画面 |
| 新規登録 | 登録後、そのままメンバーの画面に入る |
| 症例を登録 | 右上が「保存中…」→「保存済み」 |
| データ用スプレッドシートを開く | `members` に、テスト用の氏名の行が1行できている（氏名・ハッシュ化されたパスコードなど。元のパスコードは書かれていません） |

**うまくいかないとき**：下の表の症状が出たら、[困ったとき](#困ったとき)の表の対処を見てください。

| 症状 | 見るところ |
|---|---|
| ログイン画面ではなく、エラーの文字が出る | [困ったとき](#困ったとき)の最初の3行 |
| 「ファイルを開くことができません」 | URLが `/exec` か、「アクセスできるユーザー」が「全員」か |
| 管理者でログインできない | 管理者パスコードが `Code.gs` と同じか。コードを直したなら、**新しいバージョンでデプロイし直した**か |

## 手順7. Googleサイトに埋め込む（任意）

Googleサイトに載せなくても、手順5のURLをメンバーに伝えれば使えます。サイトにまとめたい場合の手順です。**スマートフォンで使う人が多いときは、埋め込みよりも、URLを直接開くほうが使いやすいです。**

**やること**

1. <https://sites.google.com> で、新しいサイトを作る（または、既存のサイトを開く）。**新しい Google サイト**を使います（旧 Google サイトは対象外です）
2. 右側のパネルの **「挿入」タブ → 「埋め込む」** を押す
3. **「URL」タブ**に、手順5のURL（`…/exec`）を貼り付けて「次へ」→ プレビューが出たら **「挿入」**
4. 埋め込まれた枠の角（または、枠を選んだときに出る点）をドラッグして、**大きく広げる**（横いっぱい、縦は画面いっぱい以上がおすすめ）
5. 右上の **「公開」** を押して、サイトのアドレスを決めて公開する

**確認**

- サイトのプレビュー（上の目のアイコン）で、ログイン画面が表示される
- 公開したアドレスを、**シークレットウィンドウで開いて**、ログインできる

> **公開範囲（誰がサイトを見られるか）は、Googleサイト側の設定です。** メンバー以外に見せたくないときは、サイトの共有設定で制限してください。ただし、**サイトを制限しても、手順5のURLを直接知っている人は、アプリのログイン画面までは開けます**（中に入るには、招待コードか、氏名とパスコードが必要です）。URLは、メンバー以外に広めないでください。

**埋め込みのときの注意（ブラウザや設定によります）**

- ダウンロード（様式の出力・バックアップ）が動かないことがあります。その場合は、アプリの画面の一番下にある **「別のタブで開く」** のリンクから開き直して、そこで操作してください
- 同じく、ログイン状態や、読み込んだ様式がブラウザに残らず、**開くたびにログイン・様式の選び直し**になることがあります。この場合も、「別のタブで開く」から使うと改善します
- 埋め込みの枠の中が真っ白になったときは、サイトのページを再読み込みしてください。それでも直らないときは、URLが `/exec` で終わっているか、「アクセスできるユーザー」が「全員」かを確認します

## 運用

### 管理者の画面

ログイン画面の **「管理者」** タブに、管理者パスコードを入れると入れます。メンバーとして登録している人は、メンバー画面の **「管理者として入る」** から、管理者パスコードを入れて切り替えることもできます（メンバー画面にも戻れます）。

| 画面 | できること |
|---|---|
| 全員の進捗 | 全員の進捗（3つの専門医）、入学年度、受験予定日、残り日数、不足件数、週あたりのペースの一覧。**入学年度で絞り込み**、並べ替え、氏名の検索ができる。氏名を押すと、そのメンバーの記録を**閲覧のみ**で開き、研修手帳の様式（基本領域・診断・治療の3種類）・Excel・CSVで出力できる |
| メンバー管理 | 氏名の変更、**パスコードの再設定**、メンバーの削除（2段階の確認。記録も消える） |
| 全員出力 | 全員分をExcel（集計＋症例一覧）・CSVで保存。「スプレッドシートに書き出す」を押すと、データ用スプレッドシートに `全員サマリ` `全員症例一覧` のシートができて、そのURLが開ける（確認・印刷用） |

管理者が他のメンバーの記録を書き換えることはできません（閲覧のみ）。

### メンバーの追加・削除・パスコードの再設定

- **追加**：招待コードを伝えて、本人に「新規登録」してもらう（管理者が代わりに登録する機能はありません）
- **パスコードを忘れたとき**：管理者画面の「メンバー管理」で、そのメンバーのパスコードを再設定して、新しいパスコードを本人に伝える。メンバー本人は、ログイン後の「設定」でパスコードを変えられます
- **氏名の表記を直したいとき**：「メンバー管理」で氏名を変更する（同じ氏名は登録できません。全角・半角、スペースの有無、大文字小文字の違いは同じ氏名として扱います）
- **卒業・退会**：必要なら先に「全員出力」で保存してから、「メンバー管理」で削除する

### 毎年の使い回し

データを消さずに、そのまま使い続けられます。

1. 新しい年度の人に、招待コードを案内して登録してもらう
2. 各自に、「設定」で**入学年度**と**受験予定日**を入れてもらう
3. 管理者画面の「全員の進捗」で、**入学年度で絞り込んで**見る

招待コードを年度ごとに変えたいときは、`Code.gs` の `JOIN_CODE` を書き換えて、[新しい版に更新するとき](#新しい版に更新するとき)の手順4（新バージョンのデプロイ）をします。すでに登録済みのメンバーには影響しません。

### バックアップ

- **データ用スプレッドシートのコピー**：ドライブでスプレッドシートを開き、「ファイル → コピーを作成」で、ときどき（月1回など）コピーを残す。「ファイル → 変更履歴」でも、以前の状態を見られます
- **各自のバックアップ**：メンバーには、「出力・バックアップ」タブの「バックアップを保存」（JSON）を、ときどき保存してもらう
- **データ用スプレッドシートを消さない・中身を直接書き換えない**。誤って削除すると、`setup` を実行したときに空のスプレッドシートが新しく作られ、以前のデータにはつながらなくなります（ゴミ箱に残っている間なら戻せます）

### 管理者を交代するとき・アカウントをなくすとき

データは、**管理者のGoogleアカウントのドライブ**にあります。アカウントがなくなると、データも、URLも使えなくなります。異動や退職の前に、次の準備をしてください。

1. 「全員出力」で、全員の記録をExcelで保存する
2. 各メンバーに、「バックアップを保存」（JSON）を保存してもらう
3. 新しい管理者が、**手順0〜7で、新しく作る**（新しいURLができます）
4. メンバーに、新しいURLと招待コードを案内して、新規登録してもらい、各自のバックアップを「バックアップから復元」で戻してもらう

## 新しい版に更新するとき

アプリが新しくなったときの手順です。**URLは変わりません。** 変わったファイルだけ差し替えます（どちらが変わったか分からなければ、両方を差し替えます）。

**やること**

1. 新しい ZIP をダウンロードして解凍する（手順0）
2. Apps Script のエディタを開く（<https://script.google.com> の「マイプロジェクト」から、作ったプロジェクトを開く）
3. 変わったファイルの中身を、**すべて選択して削除し、新しい内容を貼り付けて**、保存する
   - `Index.html` ：画面の変更。これだけ差し替えれば足りることがほとんどです
   - `Code.gs` ：サーバー側の変更。**置き換えると、先頭の2つのコードが空に戻ります。** 管理者パスコードと招待コードを、**もとと同じものに書き直して**から保存してください（別のものにしたい場合を除く）。書き直さずにデプロイすると、「初期設定が終わっていません」と表示されます
4. `Code.gs` を差し替えた場合は、関数 `setup` をもう一度実行する（データは消えません）
5. **「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → 「バージョン」を「新バージョン」にして →「デプロイ」** を押す（**保存しただけでは、メンバーが使っているURLには反映されません**）

**確認**

- 「デプロイを管理」の画面で、バージョンの番号が、前より1つ増えている
- シークレットウィンドウで、URLを開き直して（再読み込みも）、変更が反映されている。管理者パスコードでログインできる

2つのコードは、あなた自身が分かる場所（パスワード管理ツールなど）にも控えておくと、更新のときに楽です。

## 安全面と制限

### 誰が何を見られるか

| 誰が | 見られるもの |
|---|---|
| メンバー本人 | 自分の記録だけ |
| 管理者（管理者パスコードを知っている人） | 全員の記録（閲覧のみ） |
| **スクリプトの持ち主（管理者のGoogleアカウント）** | **すべて。** データ用スプレッドシートを直接開けば、全員の症例が読めます。`Code.gs` には2つのコードが平文で書いてあります |

- **データ用スプレッドシートを、他の人に共有しないでください**（共有すると、全員分の症例が読めてしまいます）。`Code.gs`（スクリプト）の編集権限も、渡さないでください
- メンバーのパスコードは、塩（ソルト）つきのSHA-256のハッシュでシートに保存され、管理者にも元のパスコードは分かりません（管理者にできるのは「再設定」だけ）
- URL を知っていれば、誰でもログイン画面は開けます。中に入るには、招待コード（新規登録）か、氏名とパスコード（ログイン）が必要です。ログイン（氏名ごと）・招待コード・管理者パスコードは、それぞれ5回続けて間違えると、15分ほど入力できなくなります
- ログイン状態は30日続きます

### 患者さんの情報について

このアプリは、患者ID・患者氏名・生年月日の入力欄を持たず、レポート一覧の取り込みでもそれらの列を読みません。それでも、年齢・性別・検査日・診断名などの組み合わせは、状況によっては個人が推定されることがあります。**症例の情報を院外のクラウドに置くこと自体が、所属施設の規程で制限されている場合があります。** 使い始める前に、所属施設の情報セキュリティ・倫理の担当に確認してください。

### 上限・目安

- 数十人規模を想定しています
- 登録できるメンバーは500人まで
- 1人・1か月あたり、約64万文字（数千件）まで保存できます
- 同時に保存する人が多いと、「混み合っています」と出ることがあります（少し待って、もう一度）
- Googleの無料アカウントには、1日あたりの使用量の上限があります。上限に達すると、「Service invoked too many times」などのエラーが出て、しばらく（24時間以内に）使えなくなります。数十人が日常的に症例を登録する使い方では、ふつう問題になりませんが、まとめて多くの人が同時に使う場面（例：説明会で全員が一斉に登録）は避けると安心です

## 学会の様式の扱い

- `apps-script/Index.html` には、**学会・機構の様式ファイルは含まれていません。** 様式への書き込み出力を使う人は、アプリの「出力・バックアップ」タブで、様式のExcel（.xlsx）を選びます。**放射線科専門医（基本領域）、診断専門医、治療専門医の3種類に対応**しており、中身から自動で判別します。一度選ぶとブラウザに保存されます（埋め込み画面などでは保存されず、そのつど選び直しになることがあります）
- 管理者がメンバーの記録を開いたときも、様式の出力には、管理者のブラウザで様式を選ぶ必要があります（画面上部に選択欄が出ます）。3種類の出力ボタンが並びます
- **様式を内蔵した版を作ってApps Scriptで配ることは、おすすめしません。** 内蔵版の `Index.html` は、ログインする前でも、URLを知っている人なら誰でも様式を取り出せてしまいます。学会の様式の取り扱い条件に注意してください。作り方は、リポジトリのトップの README（「様式を内蔵した私用版」）にあります
