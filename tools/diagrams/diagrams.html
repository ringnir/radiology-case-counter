2つのコードを書き込む（手順2）

Code.gs の先頭近くにある2行の、引用符 ' ' の間だけを書き換えます。

変更前
const ADMIN_PASSCODE = '';  // 管理者パスコード（8文字以上）
const JOIN_CODE = '';  // 招待コード（6文字以上）
変更後（例。この例は使わず、自分で決めたものを書く）
const ADMIN_PASSCODE = 'kanri-2026-xyz';
const JOIN_CODE = 'nyugaku2026';
○ よい例
半角の英数字と - _ だけ
引用符 ' ' は消さない
行末の ; も消さない
× だめな例
全角文字・空白
'（引用符）・"・\ を中に入れる
2つのコードを同じ文字列にする
文字数
管理者パスコード：8文字以上
招待コード：6文字以上
足りないと「初期設定が終わっていません」と出ます

ウェブアプリとしてデプロイする（手順5）

エディタ右上の「デプロイ」→「新しいデプロイ」を押すと、設定の画面が開きます。

新しいデプロイ
ウェブアプリ
（空欄でも、「初版」でもよい）
自分（あなたのメールアドレス）
全員
キャンセル デプロイ
設定は3か所だけ
① 種類は「ウェブアプリ」（歯車のアイコンで選ぶ）
② 次のユーザーとして実行は「自分」
③ アクセスできるユーザーは「全員」
「Google アカウントを持つ全員」ではありません。メンバーがGoogleにログインしなくても使えるようにするため、「全員」にします。アプリ自体のログイン（氏名＋パスコード）があるので、中身は見られません。
デプロイが終わると
「デプロイを更新しました」と出て、ウェブアプリのURLが表示されます。
「コピー」を押して、メモ帳などに貼り付けて保存します。
https://script.google.com/macros/s/（長い英数字）/exec
末尾が /exec のものを使います。/dev で終わるURLは自分専用のテスト用なので、メンバーには渡しません。
